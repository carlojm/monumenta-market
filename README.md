# Monumenta Market Directory

[Monumenta](https://playmonumenta.com/) is an MMORPG built entirely inside Minecraft, based on the Complete-the-Monument subgenre of Minecraft maps. The economy is based entirely around player-run shop plots on one large market island. This market can be hard to navigate and hard to catalog, as it is constantly changing with shops opening, closing, moving, and restocking all the time.

This project started as an ingame shop plot containing a map of the island and shops catalogued through notes sorted into barrels. It then evolved into a Google Doc, making it easier to Ctrl-F search for the items you are looking to buy and sell. After a few years of iterating on this project, I have built this site to solve the problems that caused the document and ingame versions to become stagnant. This site is built with maintainability as the main goal: there are multiple ways for players to contribute info about shops, and admin tools that allow moderators and shop owners to keep each shop page up to date.
